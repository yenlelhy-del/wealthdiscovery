# FinPeace Wealth Discovery

Pre-meeting KYC for FinPeace Strategic Financial Coaching.

## Deployment
Target: `https://finpeace.cloud/wealth-discovery/` on Ubuntu VPS, Nginx, Node.js 20, port 3101 bound to localhost.

**Security:** Never commit customer KYC submissions, secrets, server keys, `.env`, or VPS backups. Production go-live requires verified privacy policy, protected storage, backups, rate limiting, and security testing.
